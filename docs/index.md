## Two ways to use it

Sheet Tailor works on two levels, and you choose how much you want to change.

**Customize the system's sheet.** You keep the sheet you already know and only adjust it: move blocks, change colors, hide what you don't use and put artwork behind it.

![The D&D 5e sheet being customized: a block is dragged and artwork appears behind it](/media/01-customize-dnd5e.gif)

**Freeform Sheet.** A new sheet, complete from the first click, that you can build on your own art, across several pages.

![The D&D 5e Freeform Sheet, with the tabs of the system sheet and working rolls](/media/03-freeform-dnd5e.gif)

Both work together: the customized system sheet also shows in the last tab of the Freeform Sheet.

## Systems

| System | Support |
| --- | --- |
| D&D 5e | dedicated: rolls, items, spells, advancement when classes are dropped |
| Pathfinder 2e | dedicated: strikes with the multiple attack penalty, spellcasting entries, conditions |
| FateX | dedicated: aspects, consequences, stress, skills, stunts |
| Any other | through the data path, with the system sheet in the last tab |

See [Installation](/guide/installation) for the verified versions.

# Configurações e permissões

## Configurações do módulo

As configurações ficam em **Game Settings** → **Configure Settings** → **Sheet Tailor**.

![As configurações do Sheet Tailor: o botão Discord e a opção Quem pode editar o layout das fichas](/img/pt/configuracoes.png)

| Configuração | O que faz |
| --- | --- |
| **Quem pode editar o layout das fichas** | **Donos do ator e Mestres** (padrão): cada jogador monta o layout e personaliza a ficha dos personagens que são dele. **Somente Mestres**: só o Mestre edita; os jogadores usam as fichas normalmente, sem o botão de régua e lápis e sem **Personalizar ficha**. |
| **Discord** | Abre o convite para a comunidade no Discord: suporte, novidades e sugestões. |

## Quem pode fazer o quê

| Ação | Quem pode |
| --- | --- |
| Ver o layout e a personalização | Todos que podem abrir a ficha do personagem |
| Digitar, marcar e rolar na ficha | Quem pode editar o personagem (o dono e o Mestre) |
| Editar o layout e personalizar a ficha | Donos e Mestre; só o Mestre, com **Somente Mestres** |
| Salvar modelos de personalização para a mesa | Só o Mestre |
| Aplicar um modelo de personalização | Qualquer dono, na ficha do próprio personagem |
| Escolher a Ficha Livre para um personagem | Quem pode configurar a ficha daquele personagem; para virar a ficha padrão de um tipo, o Mestre |

## Enviar imagens

Escolher uma arte pelo botão de pasta usa o navegador de arquivos do Foundry. Para isso, o jogador precisa da permissão **Use File Browser** e, para mandar arquivos novos, da permissão **Upload Files**. O Mestre libera as duas em **Game Settings** → **Configure Settings** → **Core** → **Configure Permissions**.

Sem essas permissões, o jogador ainda pode colar o endereço (URL) de uma imagem no campo de fundo. O endereço precisa ser acessível para todos os jogadores, não só para quem colou.

## Onde ficam os dados

| O quê | Onde |
| --- | --- |
| Layout da Ficha Livre | No personagem |
| Personalização da ficha do sistema | No personagem |
| Valores personalizados | No personagem |
| Modelos de personalização | No mundo |
| Aba aberta da Ficha Livre | No navegador de cada pessoa |

Como quase tudo fica no personagem, duplicar, exportar ou guardar o personagem num compêndio leva o layout junto.
